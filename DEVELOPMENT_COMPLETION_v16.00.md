# Karyalay Portal v16.00 - Development Completion

Release date: 2026-09-10
Type: Major feature release
Previous: v15.01

## Scope completed

- Added 16 user-selectable account theme presets across 8 color families.
- Every family provides both Light and Dark variants.
- Theme preview is immediate; Save Theme as My Default persists the selected combined preset to the user's profile.
- Existing `smvs`, `slack` and `google` values remain backward compatible and are normalized in the UI.
- New users default to SMVS Teal Dark.
- User Guide HTML is updated and remains governed by role/department/user page entitlements.
- Existing role/user/network/external-access, healthcheck, and persistent-media behavior is preserved.

## Runtime status

Development coding and static validation are complete for this release. Integrated browser/UAT, production performance, real provider/integration checks and final Go-Live evidence remain separate deployment-stage gates and are not marked complete here.
