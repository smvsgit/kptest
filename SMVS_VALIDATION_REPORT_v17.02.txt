- Selecting several still posts to /files/bulk-download and returns a ZIP.
- Action bar reads "Download" for one file and "Download ZIP" for several, and
  the count label is singular/plural correct.
- Each card carries a download button, shown when the file is downloadable, so a
  single asset can be saved without opening the preview.
