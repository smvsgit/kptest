ROOT-CAUSE ANALYSIS
- Deployment/build completed, but the app health endpoint failed after startup.
- First real error visible in the supplied Coolify/browser screenshot:
  require(/var/www/html/bootstrap/cache/config.php): Failed to open stream: Permission denied
- The following `ReflectionException: Class "config" does not exist` is secondary fallout because Laravel could not load its generated cached configuration file.
- v13.04 entrypoint generated a persistent APP_KEY with a process-wide `umask 077` and never restored the umask.
- On a fresh resource where APP_KEY is generated, later root-run Laravel cache commands therefore created files such as bootstrap/cache/config.php with mode 0600/root ownership. Apache runs as www-data and could not read those files, so `/up` and normal web requests failed.

FIXES APPLIED
1. Scoped `umask 077` to a subshell used only when writing storage/app/.runtime-app-key.
2. Explicitly set `umask 022` before Laravel runtime/cache generation.
3. After package/config/route/view cache generation, normalize bootstrap/cache and compiled-view ownership/modes for Apache readability.
4. Preserved the v13.04 npm/Coolify and lucide-react/Vite fixes.
5. Preserved persistent media bind mount on app + worker + scheduler:
   /srv/media/projects/karyalayportal/uploads:/var/www/html/storage/app/media/uploads
6. No destructive DB operation, schema change, business-feature change, or media-path migration was introduced.
