V08.00 FUNCTIONAL SCOPE PRESENT IN SOURCE
-----------------------------------------
1. Notification delivery orchestration
   - Portal / in-app notifications delivered synchronously.
   - Email, WhatsApp and Text SMS deliveries queued through retryable jobs.
   - Central Admin global channel switches + per-event routing matrix are enforced.
   - User preferences can further disable allowed channels/categories but cannot enable a channel globally disabled by Central Admin.
   - Delivery status/attempt/error/provider metadata is persisted in notification_deliveries.

2. Provider support
   - Email: SMTP with Central Admin host/port/encryption/username/password/from settings.
   - WhatsApp: Meta Cloud API or generic HTTP endpoint using encrypted token.
   - Text SMS: generic HTTP provider using encrypted API key and sender id.
   - Test-send actions are available from Central Admin Notifications settings.

3. Notification Center & preferences
   - Full notification list with unread/read state.
   - Mark one / mark all read.
   - Category filtering.
   - Per-user channel/category preferences.

4. Access-request escalation
   - Configurable enable/disable, first-after-hours, repeat interval and maximum escalation count.
   - Scheduled command notifications:escalate-access.
   - Docker Compose scheduler service runs Laravel schedule:work.
   - Escalation is OFF by default until Central Admin explicitly enables it.

5. Audit integrity / coverage
   - Who / What / When plus IP, user-agent, session id and source context.
   - Before/after context on critical configuration/content actions where implemented.
   - Ordered SHA-256 previous_hash -> record_hash chain.
   - Laravel model-level update/delete protection.
   - MariaDB/MySQL database triggers prevent audit row UPDATE/DELETE.
   - Audit-integrity verification service/report endpoint.
   - Additional events include authentication, access workflow, media lifecycle, bulk operations, user/department/category and Central Admin settings/report exports.

6. Dashboards / reports
   - Role-scoped summary metrics for Super Admin, Department Admin and user views.
   - Access report.
   - Activity / admin/security report.
   - Notification delivery report for Super Admin.
   - CSV export.
   - Browser Print / Save as PDF workflow.
   - Dedicated server-side PDF/Excel export is intentionally not claimed complete and remains WIP in the tracker.

SECURITY / GOVERNANCE NOTES
---------------------------
- Email passwords, WhatsApp tokens and SMS API keys are encrypted before persistence; browser props expose saved/masked state rather than plaintext credentials.
- User notification preferences cannot override a channel disabled by Central Admin.
- Portal reports are role/department scoped; notification-delivery report is Super Admin-only.
- Audit logs are append-only in application code, hash chained and database-trigger protected on MariaDB/MySQL.
- Audit retention is NOT auto-deleting records because Management has not yet approved the audit-retention policy.
- Notification escalation defaults to OFF; Central Admin must approve/configure timing before enabling.
- Provider credentials, sender identities, channel activation and provider compliance remain deployment/operations responsibilities.
