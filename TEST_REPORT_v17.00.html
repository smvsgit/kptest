2. Defects fixed while clearing the failing suites

Fixing the seven previously-failing tests surfaced three genuine application defects (marked App) alongside three stale tests (Test). The application defects were breaking real flows in production, not just the suite.
KindDefectWhat was wrongFixStatus
AppJSON endpoints returned HTML redirectsbootstrap/app.php limited JSON error rendering to api/*. Every fetch caller on a web route (access request, access policy, saved search, bulk edit) got a 302 HTML redirect instead of a 422/403 body, so the UI could only show a generic fallback message.Render JSON whenever the caller asks for it, excluding Inertia visits which need the redirect flow.Fixed
AppDepartment transfer always rejectedRule::exists(...)->where('is_system', false) serialises false to an empty string, so it matched no row. Bulk department transfer failed with “The selected department id is invalid” for every valid department.Pass 0/1 instead of booleans in the exists rule.Fixed
AppXLSX import read back index numbersXlsxService::read() compared a SimpleXMLElement attribute to a string with ===, which is always false. Shared strings were never resolved, so user XLSX import saw 0, 1, 2 instead of the column text and skipped every row.Cast the attribute before comparing.Fixed
TestVersion assertion pinned to v14.00The test hard-coded 14.00/13.06 while the app ships 16.00/15.01, so it broke on every release.Assert the contract from VERSIONING.md instead: config matches the root VERSION file and moves forward.Fixed
TestStale model made a re-enable a no-opThe integration-health test re-enabled a source through an instance that predated the disabling request, so nothing was dirty and no UPDATE was issued.Refresh the model before updating it.Fixed
TestExpiry never exercisedThe temporary-approval test used a requester inside the file’s own department, where preview is granted on department membership alone — the expired entitlement was never consulted.Use a cross-department requester, and add a companion test for the still-valid case.Fixed
